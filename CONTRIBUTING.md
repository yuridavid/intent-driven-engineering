# Contributing

Every contribution must:

- support the North Star;
- preserve technology independence;
- avoid duplicate concepts;
- state the problem being solved;
- identify affected concepts;
- include evidence when changing Foundational or Core Knowledge;
- preserve a single authoritative definition for each concept.

## Workflow

1. Record the observation or hypothesis.
2. Gather supporting and contradicting evidence.
3. Identify affected concepts.
4. Write an ADR for material decisions.
5. Review against the Constitution and Authoring Guide.
6. Promote accepted content into the IDE-BoK.

## Pull request checklist

- [ ] Supports the North Star.
- [ ] Reduces uncertainty or improves coherence.
- [ ] Does not duplicate an existing concept.
- [ ] Uses technology-independent definitions.
- [ ] Makes dependencies and relationships explicit.
- [ ] Separates experimental claims from canonical knowledge.
- [ ] Updates affected indexes and diagrams.
