# Concept Model

The IDE-BoK is composed of connected concepts, not isolated chapters.

## Concept anatomy

```text
Concept
├── Identity
├── Definition
├── Purpose
├── Problem Solved
├── Inputs
├── Outputs
├── Dependencies
├── Consumers
├── Quality Criteria
├── Relationships
├── Common Mistakes
├── Examples
├── Evidence
└── Change History
```

## Relationship types

- `depends-on`
- `produces`
- `validates`
- `constrains`
- `informs`
- `evolves`
- `contrasts-with`

Every Core concept should have at least one incoming relationship, one outgoing relationship, an explicit boundary, and no duplicate semantic ownership.
