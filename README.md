# Intent-Driven Engineering

This repository contains the **Intent-Driven Engineering Body of Knowledge (IDE-BoK)**.

## North Star

> Preserve business intent while continuously reducing uncertainty across every engineering transformation.

## Repository model

```text
Research
   ↓
Validation
   ↓
Governance Review
   ↓
IDE-BoK
   ↓
Playbooks / Skills / Book / Training / Visual Assets
```

## Structure

- `ide-bok/`: authoritative knowledge.
- `research/`: hypotheses and work under evaluation.
- `templates/`: reusable authoring and operational templates.
- `governance/`: decisions, ownership, and contribution rules.
- `assets/`: diagrams, infographics, and cards.
- `skills/`: AI skills derived from the IDE-BoK.
- `examples/`: practical cases.
- `docs/`: roadmap and derived documentation.

The canonical version is maintained in English. Translations may simplify or contextualize, but must not redefine canonical concepts.
